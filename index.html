Sobre a simplificação da navegação

A versão anterior deste guia usava um mega menu com 8 grupos (Institucional, Conteúdos, Temas, Programa de Recompensas, Participe, Eventos, Recursos, Novidades). Revisamos essa decisão: o briefing confirma apenas três públicos e um conjunto menor de páginas, então a navegação foi reduzida para não sugerir escopo que ainda não foi fechado com o cliente.

Por que simplificar
  • O briefing define 3 públicos (pais, doadores, pesquisadores) — a Home e o menu devem refletir só isso.
  • Um mega menu de 8 grupos sugere ao cliente funcionalidades (newsletter, trilhas, voluntariado) que ainda não têm escopo confirmado.
  • Menos destinos no topo reduz a sensação de "40 caminhos possíveis" para quem chega pela primeira vez.
  • "Programa de Recompensas" deixa de competir como item de primeiro nível — vira "Como Funciona" + "Loja", com nome de produto próprio (Estação dos Porquês) só dentro da experiência.
Pontos de atenção
  • Conforme o site crescer, "Conteúdos" pode precisar de um item a mais (ex.: Concurso) — só adicionar quando estiver ativo.
  • Itens institucionais que existiam no mega menu (Quem somos, Missão, Equipe, Parcerias) precisam de um novo lar — sugerimos dentro de "O Clube".
  • Sem mega menu, o rodapé passa a carregar mais peso de navegação secundária — vale revisar seus links.
Nossa recomendação

Validar esta estrutura enxuta (O Clube · Como Funciona · Conteúdos · Loja · Doe · Entrar) antes de evoluir para um menu maior. Só adicionar um novo item de primeiro nível quando uma página tiver conteúdo publicado e público confirmado — nunca para "deixar reservado".

01 — Fundamentos

Princípios de marca

Quatro ideias que orientam toda decisão visual e de produto. Quando houver dúvida, volte a elas.

01

Curiosidade em primeiro lugar

A interface convida à exploração. Cada tela abre uma pergunta e recompensa quem investiga — como um verdadeiro laboratório.

02

Colorido com propósito

A paleta viva do logo é usada com intenção: cor guia a atenção e organiza a informação, nunca só decora.

03

Acessível para todos

Contraste, tamanhos de toque e linguagem clara. Um público jovem e diverso precisa entender sem esforço.

04

Consistente e reaproveitável

Tokens e componentes se repetem em todo o site. O que se define aqui se propaga por todas as páginas do Wix.

13 — Implementação

Notas de implementação no Wix

Regra de ouro: sempre a solução mais nativa e simples possível. Só suba de nível quando a anterior não resolver.

1. Nativo Wix Studiopreferência máxima

Elementos do editor: botões, inputs, tabs, accordions, header/menu, lightbox, grid/stack e o Site Theme (cores e tipografia). Cobre a maior parte do sistema sem código.

2. Wix CMS

Coleções + Repeaters para todo conteúdo dinâmico: pesquisadores, missões, artigos, recompensas. Estrutura os dados uma vez e o layout se repete sozinho.

3. CSS custom

Ajustes finos de estilo (sombras específicas, badges, micro-estados) quando o editor não expõe a propriedade. Use com parcimônia.

4. Custom Element

Componentes que o Wix não oferece nativamente (widgets ricos, carregar fontes, visual muito específico). Encapsula HTML/CSS/JS próprios.

5. Velo (código)último recurso

Lógica e interatividade: troca de abas, resgate de recompensas, workflow de status, pagamentos (Wix Pay), cálculo de pontos. Só onde há regra de negócio.
